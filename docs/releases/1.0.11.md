# Xcss 1.0.11

输入框和下拉触发框在小数尺寸、高像素比及缩放下，使用现有 SVG 轮廓在边框盒内精确绘制，消除右侧额外细条并保留完整边线。无外部阴影、可见外轮廓或图片背景的有边框控件使用此路径；需要外部绘制空间的控件保留原有路径。两者复用同一个 Mac mini 轮廓。

下拉面板仍只有外层圆角，前景灰色边线完整且统一线宽；箭头垂直居中，关闭为 `>`、展开旋转 90 度；输入框聚焦不添加粗外框或替代细线。

修正浏览器测试辅助函数，使其能读取实际的 SVG 绘制来源，继续验证原有轮廓、四角尺寸、主题和样式恢复，不要求所有控件使用同一种 CSS 绘制属性。

Rust crate、Web 包及工具统一为 `1.0.11`。已有发行资产与 `v1.0.10` 标签保持不变；`v1.0.10` 的发行检查失败且未发布归档。
