# Xcss 1.0.9

输入框、文本区域、选择框和组合框聚焦时去掉粗外轮廓，不新增细边线或替代聚焦装饰；控件原有边框保持不变。

共享单选下拉框使用居中的 SVG `>` 箭头，展开时旋转 90 度；箭头尺寸与位置在开合时保持一致。

展开面板在现有 `server-corners` 完成轮廓及阴影绘制后才显示，避免首次显示时先出现直角。整个面板的四角沿用同一个 Mac mini 轮廓，条目保持直边，首尾交互背景由外层裁切。系统强制色彩模式使用原有系统色边界。

下拉面板的灰色边线单独绘制在选项上层，复用同一轮廓及其内向平行曲线；圆角与四条直边统一线宽，选项背景不能遮住边线，滚动不移动面板外边线。

原生表单值、必填校验、禁用、重置、键盘操作、关联标签、多选列表和首个无效字段聚焦合同保持不变。Rust crate、Web 包及工具版本统一为 `1.0.9`。消费者固定新发行的完整源码修订和归档完整性摘要；此前的 `1.0.8` 发行资产保持不可变。
