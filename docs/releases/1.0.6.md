# Xcss 1.0.6

管理 Web 将西文与 CJK 字形合并为两个完整的 Regular/Bold 字体，移除项目自行生成的 Unicode 分片和 Bootstrap 字体。启动门控等待两个字体全部加载并解码后再显示界面。上游 Maple 项目保持原样。

圆角渲染器复用已经取得的样式与尺寸，减少大批元素更新时的重复布局读取。单个字体预算为 16 MiB，其他资源预算保持原值。

Rust crate、Web 包和随附工具统一为 `1.0.6`。消费者同步固定完整 Git revision、发行包 URL 与实际 SHA-512 摘要。该版本不提供旧字体导出兼容入口。当前为本地准备的发行输入，正式发布后才能在其他环境直接获取。
