# XCSS 1.0.15

修复登录计数身份的实际复用错误：注册表只读固定已验证的主数据库文件描述符，使已删除但计数尚未到期的数据库 inode 不能被另一安装复用。内存数据库固定连接参数对象，防止分配器复用地址导致不同池共享计数。

同一数据库的新 Store、Service 或连接池仍共享原计数，独立数据库分别计数。每个 60 秒窗口 60 次、全进程密码计算并发 2 及 256 个范围的上限保持一致。到期且无使用者时，条目回收同时关闭身份描述符，不取得 SQLite 或维护锁，不改写源文件。

配置整数关系规则增加严格小于与正整数单位倍率，使用检查乘法拒绝溢出；原有小于等于仍由同一实现验证。产品可同源描述时间单位关系与保留周期的严格顺序，无需复制约束参数。

1.0.14 的标签保留原源码；该版本的发行 CI 在认证回归中发现此错误并拒绝生成资产。本版本使用新的不可变标签与发行资产，数据库 DDL 与当前构建 API 不需要转换。
