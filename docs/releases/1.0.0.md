# XCSS 1.0.0

当前基线将 Rust crate、唯一的 `@xcss/web` 包和 Python 发行工具统一为 `1.0.0`。平台代际、数据库结构修订、结构指纹算法、状态合同、备份清单和管理员策略的自有版本均为 `1`；第三方软件和标准协议保留实际版本。当前基线不读取旧格式，不提供数据迁移入口。

服务端运行接口要求显式的绝对 `--root`，安装、配置初始化和升级由独立工具完成。管理员账号、会话、登录尝试限制和审计共用一套定义。由管理员控制的配置支持服务账号同组只读，仍拒绝可写、非私有、链接或权限不合规的文件。公共 HTTP 诊断和业务日志共用进程日志接收器。

Web 保留统一的圆角控件、UTC 时间和全量字体启动等待。共享前端只发行一个 `xcss-web-1.0.0.tgz`；服务端消费者编译嵌入已构建并验证的前端。正式运行不依赖开发目录。

发行资产只使用 SHA-256 校验，不要求自定义发行签名。业务 TLS、密码散列和数据加密继续使用各自的标准安全机制。消费者固定 Rust 精确版本、完整 Git revision，以及实际发行 Web 归档和完整性摘要，更新锁文件后重建、测试。

构建和验收见[开发指南](../development.md)，正式发行输入和产物核验见[发行操作](../operations.md)。
