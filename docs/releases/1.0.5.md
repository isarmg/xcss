# Xcss 1.0.5

- 修复圆角范围过渡期间移除元素后持续请求动画帧的问题；按元素记录并清理过渡状态，同时保留同一元素与伪元素的并行过渡。

- 保留日志目录、文件身份和长度校验，拒绝意外的外部写入；补充部分写入、轮转恢复与元素移除的回归测试。
