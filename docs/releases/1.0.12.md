# XCSS 1.0.12

移除访问者 IP 解析和按 IP、账号、会话累计失败限流。管理员 HTTP 正文保持全局 32 个读取槽，密码计算和会话安全规则保持有界。

增加统一 offline 数据报告及持有连接的管理员校验/首次插入能力，供独立安装辅助程序调用。私有目录可校验持有句柄与路径身份，SQLite 验证支持显式 ROOT/run 临时目录和原有大小/时限预算。

Web 构建从同次 build.rs 导出资源清单和构建身份，静态核验真实二进制内的清单、摘要及每项资源字节，生成绑定 binary SHA256 的构建收据。verify-only 必须指定 receipt；不再运行候选 Server 的 web-assets CLI。

当前合同不提供旧 API 或旧 CLI 兼容。消费方须同时更新 Rust Git revision 和 @xcss/web 1.0.12 正式归档及完整性锁。

合并云端真实修复：业务操作重试成功后清除上一轮 error_code，避免完成状态仍携带失败错误。
