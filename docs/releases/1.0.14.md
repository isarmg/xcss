# XCSS 1.0.14

公共认证恢复按安装数据库物理身份共享的登录尝试次数限制：每个单调时钟 60 秒窗口最多接受 60 次尝试，成功不清零；达到上限返回 HTTP 429 和 `Retry-After`。重新创建 Store、Service 或连接池不能绕过限制。计数状态最多 256 个安装范围，密码计算仍使用全进程并发 2 的独立预算，不读取访客 IP。

新增纯构建期安装定义材料：权威 DDL、typed SQL 参数、凭据策略、结构指纹、当前秘密封装参数和验证向量。配置数据类型同源生成 JSON Schema、默认值和有限语义规则，独立安装工具消费签名材料，无需链接 Server 或 Xcss。

删除静态 JSON 管理员、内存会话、生产离线维护入口及维护交接锁。运行时保留实例锁与文件身份检查。HTTP 连接日志统一使用结构化事件，不传递或记录客户端地址。秘密封装增加显式动态 domain/revision 原语，沿用唯一当前格式。

来源检查直接验证官方 Git/NPM 来源、精确身份和完整 revision，不根据无关包的名称前缀推断归属。SBOM、审计、许可证和真实制品校验继续执行。新版本不包含旧接口或数据转换路径。
