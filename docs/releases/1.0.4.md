# Xcss 1.0.4

服务端继续采用 Mac mini 七次 Bézier 轮廓，所有圆角矩形的四角使用同一尺寸。下拉菜单和选择框的顶部、底部均为完整圆角。删除逐角覆盖和嵌套跟随 API；内外框视觉协调由组件自身的统一尺寸令牌表达，运行时不判断布局适合性，也不计算父子关联轮廓。

普通控件、面板、提示、弹窗不再包含旧圆弧回退。删除未被消费者使用的旧 6/8/12px radius 令牌及 `tokens.radius`。账号入口保留圆形，胶囊和装饰图形保持自身形状。系统强制色彩模式保留系统颜色、边界和键盘焦点。

仅支持当前最新稳定版浏览器和原生系统系列。React 与原生 ESM 构建使用 `esnext` JavaScript/CSS 目标，关闭 module-preload polyfill。

消费者同步固定 Rust `=1.0.4`、本次发行完整源码修订与 `xcss-web-1.0.4.tgz`，更新真实归档完整性摘要。旧发行归档保持不可变。
