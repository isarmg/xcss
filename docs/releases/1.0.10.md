# Xcss 1.0.10

此标签保留了已验证的绘制修复。发行检查中的旧测试辅助函数无法读取新绘制路径，因此未发布归档；正式交付见 [1.0.11](1.0.11.md)。

修正输入框和下拉触发框在小数尺寸、高像素比或缩放环境下，右侧出现额外细条的问题。保留现有 Mac mini 轮廓和原有边线宽度，不新增聚焦外框或替代细边线。

无外部阴影、可见外轮廓或图片背景的有边框控件，使用同一 SVG 在边框盒内按实际尺寸绘制，绕过 `border-image` 的分区缩放；裁切限制在边框盒内。有外部阴影或可见外轮廓的表面继续保留原有外部绘制区域，停止渲染器时恢复作者样式。

下拉面板的前景灰色轮廓、仅外层圆角、首次展开绘制门控、居中 `>` 箭头及展开旋转 90 度的行为保持一致。

Rust crate、Web 包及工具版本统一为 `1.0.10`。消费者固定新发行的完整源码修订和归档完整性摘要；已经发布的 `1.0.9` 归档保持不可变。
