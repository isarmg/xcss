# XCSS 1.0.16

管理员认证的物理数据库计数对象改用 Linux `O_PATH | O_NOFOLLOW | O_CLOEXEC` 元数据描述符固定 inode。1.0.15 使用普通只读描述符；重复构造 Store 查询同一数据库时，关闭额外描述符会释放进程持有的 SQLite POSIX 字节区间锁，允许另一进程在原写事务提交前取得写锁。

该修复保留每数据库 60 次/60 秒、最多 256 个计数对象、到期回收及 inode 防复用策略。它不修改数据库结构、认证策略修订、HTTP 错误契约或前端行为。

回归测试使用 DELETE 日志模式、两条真实 SQLite 连接和独立子进程：先证明活动写事务阻止第二个写进程，再重复构造 Store 查询计数对象，确认仍阻止竞争；提交后竞争写事务正常成功。相同测试在 1.0.15 描述符实现上失败。既有删除重建数据库隔离和有界描述符回收测试继续覆盖身份固定。

1.0.15 标签与发行资产保持不变；本补丁通过新的 1.0.16 版本发布。
