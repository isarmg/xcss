# XCSS 1.0.17

修复安装工具创建 root 所有、服务组只读的运行配置后，服务进程被私有文件读取规则拒绝的问题。

新增 `config::read_managed_file`，验证实际物理路径、root 所有的 0700/0750 父目录、同组 0600/0640 单链接文件、额外 ACL 和读取期间的身份变化。私有密码输入继续使用严格的 `read_private_file`。进程用户所有的开发文件只通过未绑定 debug 构建显式授权。

回归覆盖实际 UID33/GID33 读取安装配置、配置及安装根目录写入拒绝、其他 UID 访问拒绝，以及权限、组、符号链接、硬链接、特殊文件和大小边界。

1.0.16 标签与发行资产保持不变；本修复通过新的 1.0.17 版本发布。
