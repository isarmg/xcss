# 账户设置

`xcss_web::components::AccountPage` 是共享 Rust 账号视图，由产品正常路由承载。它展示当前管理员名，要求当前密码，可选择新密码并确认；用户名、密码及两次输入不满足当前规则时不发送请求。

保存调用同源 `/api/v1/platform/administrators/self`，由 `api` 注入内存中的 CSRF；一次提交期间只读输入并禁止重复提交。成功后清除本地会话，提示使用新凭据登录。失败清除密码并呈现固定安全信息，允许明确重试。卸载时清除已脱离 DOM 的密码字段。

当前合同不提供其他管理员创建、角色管理或兼容旧账号格式。服务端仍独立校验当前密码、唯一管理员及持久撤销。真实公共 CSR 测试覆盖不匹配阻断、CSRF、重复提交、成功重新登录、密码清除及失败重试；产品还应验证真实数据库和 HTTP 会话撤销。
