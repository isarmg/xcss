# Xcss 1.0.8

下拉选项面板统一复用现有 `server-corners` 的 Mac mini 轮廓。共享单选 `Select` 使用可由页面绘制和裁切的选项面板；面板四角使用同一轮廓，选项行保持零圆角，首尾行的交互背景由外层面板裁切。项目自身的组合框沿用相同的面板规则，未新增圆角模型。

单选控件保留键盘操作、关联标签、禁用状态和原生表单值、必填校验及重置行为。多选列表保留已有选择、空选集、数量上限和分页语义。业务时间继续统一 UTC，字体覆盖及启动门控保持原合同。

Rust crate、Web 包和工具版本统一为 `1.0.8`。浏览器验收覆盖真实表单事件、必填校验、禁用、重置、键盘操作、对话框内展开，以及首尾背景与中间选项的像素检查。消费者固定完整源码修订、不可变发行归档和完整性摘要；已有 `1.0.7` 资产保持不可变。
