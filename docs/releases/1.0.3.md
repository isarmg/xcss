# Xcss 1.0.3

Server 圆角采用用户提供的 Mac mini 外壳模型拟合出的七次 Bézier 轮廓。照片和图标沿用原始角部占比 31.0568993271%，矩形延长直线，角部等比缩放。理想曲线与直线的连接满足 G3，运行时 SVG 使用小于 0.02 CSS px 预算的离散近似。

新增 `@xcss/web/admin-ui/server-corners`。CSS 管理角色尺寸和显式嵌套关系，TypeScript 生成轮廓、法向内缩和裁切路径。合适的内外框可启用四角跟随；普通行内按钮、工具栏、输入框及其他位置不合适的控件保留独立圆角。图片悬停平移保持同一轮廓，尺寸不足时四角统一缩小。

原生 client 单独采用 iOS `.continuous` 和 Android 近似。浏览器保留背景、边框、阴影、焦点环及无 JavaScript 回退；Blob SVG 通过受控图片来源绘制。

验证：共享 Web 单元测试 93 项通过，圆角浏览器用例 28 项通过，私有页面与安全策略 1112 项检查通过，六个 server 前端候选包构建通过。
